# Dicas para melhorar qualquer prompt
Para obter resultados adequados às suas necessidades, é fundamental deixar o prompt o mais completo possível. Isso ajuda a IA a entender o que ele precisa fazer para responder às solicitações. Ou seja, em vez de escrever "*Explique marketing*", que é um comando muito abrangente e sem detalhes, procure escrever algo como "*Explique marketing digital para pequenos negócios, com exemplos práticos e linguagem simples.*" A seguir, confira um checklist rápido com dicas para escrever bons *prompts* em qualquer IA:
- Seja específico sobre o objetivo;
- Informe o nível de profundidade;
- Defina o formato da resposta (lista, passo a passo, texto curto);
- Diga para quem é a explicação;
- Acrescente contexto sempre que possível.
