# Montando um canal no Youtube Kids com IA
Estratégia e prompts com Claude para criar histórias e conteúdos infantis voltados para canais do YouTube Kids.

## Passos
1. Abra o youtube
2. Procure um canal infantil com muitas views
3. Pesquise o quanto o youtube paga por essas views
4. Tire um print do canal
5. Pesquise por Higgsfield MCP
6. Copie o link do connector
7. Configure um novo conector no Claude
8. Cole o link
9. Escreva em uma nova conversa, junto com o print tirado:
```
Analise o canal do youtube e gere um vídeo com o Higgsfield usando o mesmo estilo para o mesmo público
```
