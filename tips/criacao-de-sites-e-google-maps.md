# Criação de sites e Google Maps
Estratégia para encontrar pequenos negócios sem presença digital no Google Maps e oferecer criação de sites com IA.

## Procedimento
1. Ir ao google maps e procurar empresas com boa avaliação e que não possuam site
2. Abrir ferramenta de IA que tenha algo como um "prompt coach" e...

```
Escreva um prompt que eu possa usar no software Vibe Code para criar um site atraente para uma empresa chamada {{EMPRESA}}, que não tem página web neste momento. Com esta informação:

{{TEXTO_GOOGLE_MAPS}}
```

3. Use um serviço como https://www.landingsite.ai ou similar
4. Cole o prompt gerado

**OBS**: pode ser feito a partir de um perfil no Linkedin também, por exemplo.
