# Skills Oficiais do Claude Code
Referência das skills oficiais do Claude Code para instalação rápida via linha de comando.
## Frontend Design
Claude segue um processo completo de design thinking antes de escrever qualquer código, garantindo estrutura, criatividade e boas práticas desde o início.

```bash
npx skills add https://github.com/anthropics/skills --skill frontend-design
```
## Webapp Testing
Claude testa sua aplicação web automaticamente com Playwright, simulando cliques, formulários e fluxos reais para garantir que nada quebrou antes do deploy.

```bash
npx skills add https://github.com/anthropics/skills --skill webapp-testing
```
## MCP Builder
Crie servidores MCP de alta qualidade para integrar APIs e serviços externos ao Claude com padrões e boas práticas já embutidos.

```bash
npx skills add https://github.com/anthropics/skills --skill mcp-builder
```
## Skill Creator
Crie suas próprias skills do zero de forma interativa. O Claude faz as perguntas certas, gera a estrutura de pastas, formata `SKILL.md` e empacota os recursos.

```bash
npx skills add https://github.com/anthropics/skills --skill skill-creator
```
## Web Artifacts Builder
Construa artifacts HTML complexos no Claude.ai usando React, Tailwind CSS e outros frameworks. Entrega direto no chat, sem criar projeto, sem instalar nada.

```bash
npx skills add https://github.com/anthropics/skills --skill web-artifacts-builder
```
