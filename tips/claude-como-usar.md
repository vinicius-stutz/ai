# Como Usar o Claude
Guia prático para extrair as melhores respostas e análises aprofundadas com o assistente Claude.

| Recurso        | Descrição e Prompts Iniciais                                                                                                                                                                                                                             | Dicas e Erros Comuns                                                                                                                                                                                                                                                                                   |
| :------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Chat**       | O ponto de partida. Onde a maioria das pessoas fica para sempre.<br><br>**Comece com:** "Reescreva este e-mail para soar mais direto, mas não grosseiro"                                                                                                 | 🔴 **Dica profissional:** Ative o Pensamento Estendido + Busca antes de cada prompt. Dois cliques que mudam tudo.<br><br>⚠️ **Erro comum:** Colar sua bio e introdução em cada novo chat. Para isso que servem os Projetos.                                                                            |
| **Cowork**     | O Cowork lê seus arquivos e cria documentos reais — Excel, Word, PDF. Direto na sua pasta.<br><br>**Comece com:** "Leia meus arquivos primeiro. Depois me faça perguntas antes de começar."                                                              | 🔴 **Dica profissional:** Escreva um arquivo .md sobre você: o que você faz, como você escreve. O Claude para de soar genérico.<br><br>⚠️ **Erro comum:** Jogar 200 arquivos e torcer pelo melhor. 5 arquivos bons vencem 50 bagunçados.                                                               |
| **Projects**   | Salve suas instruções e arquivos uma vez. Cada novo chat dentro do Projeto se lembra deles.<br><br>**Experimente:** Crie um projeto 'GANCHO' → suba os 30 melhores exemplos de gancho → cada rascunho combina com sua voz.                               | 🔴 **Dica profissional:** Um Projeto por tarefa recorrente. Não crie um mega-Projeto para tudo.<br><br>⚠️ **Erro comum:** Subir 30 documentos de referência. O Claude não sabe quais importam. Você escolhe os melhores — não a IA.                                                                    |
| **Artifacts**  | O Claude cria arquivos interativos que você pode usar, editar e baixar dentro do chat.<br><br>**Comece com:** "Crie uma calculadora de orçamento mensal com campos para aluguel, mercado, transporte e assinaturas — os totais atualizam em tempo real." | 🔴 **Dica profissional:** Peça mudanças depois que ele construir. "Coloque modo escuro." "Adicione uma coluna." Artifacts são ao vivo — você itera dentro do chat.<br><br>⚠️ **Erro comum:** Achar que Artifacts são só demos. Peça o que você normalmente faria em uma planilha ou planejador.        |
| **Excel**      | Um suplemento dentro do Excel que lê suas fórmulas reais, abas e referências de células. Não texto achatado.<br><br>**Comece com:** "Por que a célula B4 está mostrando #REF? Rastreie o erro."                                                          | 🔴 **Dica profissional:** Instale: Excel → Inserir → Obter Suplementos → busque 'Claude by Anthropic.' Abra com Ctrl+Alt+C.<br><br>⚠️ **Erro comum:** Esperar macros ou VBA. Ele constrói, limpa e explica — não automatiza cliques de botão.                                                          |
| **Connectors** | Conecte Slack, Google Drive, Notion, Gamma (slides) e mais de 50 ferramentas. O Claude pesquisa nelas durante o chat.<br><br>**Comece com:** "Encontre o deck de vendas do Q3 no meu Drive" — sem upload, sem capturas de tela.                          | 🔴 **Dica profissional:** Use o conector Gamma no Cowork para ir de um prompt → outline → slides de apresentação prontos.<br><br>⚠️ **Erro comum:** Achar que sincroniza ao vivo. O Claude pesquisa suas ferramentas sob demanda. Ele não monitora 24/7.                                               |
| **Plugins**    | Pacotes de habilidades com um clique que adicionam comandos / para Vendas, Marketing, Jurídico, Dados e mais.<br><br>→ Instale o plugin de Marketing<br>→ digite /draft-post<br>→ receba um post do LinkedIn com um CTA específico.                      | 🔴 **Dica profissional:** Digite / em qualquer chat para ver todos os comandos disponíveis. É aí que está o poder real.<br><br>⚠️ **Erro comum:** Instalar todos os 11 plugins. Cada um adiciona contexto que o Claude precisa administrar. Escolha 2 plugins que realmente combinam com seu trabalho. |
| **Skills**     | Pacotes de instruções reutilizáveis que tornam o Claude melhor em tarefas específicas — automaticamente.<br><br>→ Vá em Configurações → ative Execução de Código → navegue pela biblioteca de Skills pré-construídas → instale uma.                      | 🔴 **Dica profissional:** Você pode criar as suas. Escreva um arquivo Skill.md com suas regras e diretrizes de marca.<br><br>⚠️ **Erro comum:** Confundir Skills com Projects. Projetos guardam seus arquivos. Skills ensinam o Claude como fazer uma tarefa.                                          |
