# 7 Prompts para Recolocação Profissional
Roteiro de prompts para reformular currículos, cartas de apresentação e se preparar para entrevistas.
## 1. Reescrita do Currículo à Prova de Recrutadores
```
Aja como um recrutador sênior que analisa 200 currículos por dia. Reescreva meu currículo para o cargo de {cargo desejado} em {tipo de empresa}. Substitua cada responsabilidade por uma conquista mensurável, elimine tudo o que for genérico e faça com que meu valor seja impossível de ignorar.

Currículo: {cole aqui}
```
## 2. Perfil de LinkedIn que Atrai Recrutadores
```
Reescreva meu título, a seção 'Sobre' e as 3 principais experiências do meu perfil do LinkedIn para me posicionar nas buscas de recrutadores para o cargo de {cargo desejado} no {setor ou indústria}. Faça com que cada palavra tenha peso.

Perfil atual: {cole aqui}
```
## 3. Estratégia de Candidatura Direcionada
```
Quero conseguir um cargo como {cargo} no {setor ou indústria} em {cidade/remoto}. Crie um plano de abordagem de 7 dias, focado em {tamanho ou tipo de empresa}, que inclua: sites específicos onde encontrar vagas, termos de busca e uma lista diária de ações que eu possa executar imediatamente.
```
## 4. Mensagem Fria para Recrutadores
```
Escreva uma mensagem fria no LinkedIn para um responsável de contratação da {empresa} sobre o cargo de {cargo}. Comece com uma observação concreta sobre o negócio dele, conecte essa ideia com o meu valor e termine com um pedido simples e direto. Mantenha a mensagem com menos de 80 palavras.

Minha experiência: {cole aqui}
```
## 5. Carta de Apresentação que Realmente é Lida
```
Escreva uma carta de apresentação para o cargo de {cargo} na {empresa}, que comece com uma ideia impactante em vez de "Estou me candidatando para...". Conecte minha experiência específica com as necessidades exatas da empresa e finalize transmitindo confiança. Mantenha o texto com menos de 200 palavras.

Minha experiência: {cole aqui}
Descrição do cargo: {cole aqui}
```
## 6. Sistema de Preparação para Entrevistas
```
Tenho uma entrevista para o cargo de {cargo} na {empresa}. Dê-me as 8 perguntas mais prováveis, uma estrutura de resposta sólida para cada uma usando minha experiência, e 3 perguntas inteligentes que demonstrem pensamento estratégico.

Minha experiência: {cole aqui}
```
## 7. Acompanhamento que Reabre Portas
```
Escreva uma mensagem de acompanhamento para {candidatura / entrevista / conversa de networking} com {nome} na {empresa}. Reafirme meu encaixe em uma única frase, adicione uma nova contribuição de valor que ainda não tenha mencionado e proponha um próximo passo claro sem soar insistente.
```
