# 7 Prompts Estratégicos para Gestão de Pessoas e Tempo
Prompts estratégicos para liderança, condução de conversas difíceis, feedback e gestão de tempo em equipes.

>  Substitua os campos entre `{ }` pelo seu contexto real.

## Prompt 01 — Conversa Difícil com Colaborador de Baixo Desempenho

```markdown
Me ajude a estruturar uma conversa com um colaborador com baixo desempenho.

Contexto:
- Ele tem {tempo} de empresa
- Ponto crítico: {descrever comportamento/resultado}
- Impacto no time: {explicar}

Quero:
→ Abertura que não gere defesa
→ Clareza nos pontos sem ser agressivo
→ Perguntas que levem à reflexão
→ Fechamento com próximos passos claros

Evite linguagem genérica.
```

## Prompt 02 — Feedback Difícil
Transforme feedback em algo acionável:
```markdown
Transforme o seguinte feedback em algo direto, respeitoso e acionável:

{cole seu feedback}

Considere:
- Evitar ambiguidade
- Separar fato de interpretação
- Incluir exemplos claros
- Sugerir próximos passos

Formato de saída:
→ Contexto → Ponto principal → Impacto → Ação esperada
```

> Feedback claro = time que cresce.

## Prompt 03 — Decisão Complexa
Análise estratégica no nível de pessoas e resultado. Descreva o cenário real. Sem filtro:
```markdown
Me ajude a analisar uma decisão considerando pessoas e resultado.

Cenário: {descreva a situação}

Quero:
→ 3 caminhos possíveis
→ Riscos de cada um
→ Impacto no time (curto e longo prazo)
→ Possíveis reações das pessoas
→ Recomendação com justificativa
```

> Líderes que decidem bem, decidem com dados e com empatia.

## Prompt 04 — Plano de Desenvolvimento Individual (PDI) Real
Desenvolvimento que transforma, sem ser genérico:
```markdown
Crie um plano de desenvolvimento para um colaborador com este perfil:
- Cargo: {cargo}
- Pontos fortes: {listar}
- A desenvolver: {listar}
- Objetivo: {ex: assumir mais autonomia}

Quero:
→ Ações práticas (não genéricas)
→ Frequência de acompanhamento
→ Indicadores concretos de evolução
→ Riscos comuns no desenvolvimento
```

> Desenvolver pessoas é o maior ROI de um líder.

## Prompt 05 — Organização Semanal do Líder
Clareza mental na semana de trabalho:
```markdown
Organize minha semana como líder.

- Tenho equipe de {número de pessoas} pessoas
- Responsabilidades: {listar}
- Demandas atuais: {listar}

Quero:
→ Priorização clara
→ Blocos de tempo
→ Equilíbrio operação × liderança
→ Alertas do que estou negligenciando
```

> [!NOTE] Agenda confusa = liderança confusa
> Use toda segunda-feira pela manhã, isso muda o jogo.

## Prompt 06 — Análise de Padrões do Time
Identificar padrões em nível avançado:
```markdown
Com base nesse cenário de time, me ajude a identificar padrões:

{descreva comportamentos, clima, problemas}

Quero:
→ Possíveis causas raiz
→ Padrões de comportamento
→ Riscos se nada for feito
→ Sugestões de ação como líder
```

> Seja honesto no contexto. Mais detalhe = melhor análise.

## Prompt 07 — Diagnóstico de Saúde da Equipe
Visão sistêmica do time:
```markdown
Faça um diagnóstico da saúde da minha equipe com base no contexto abaixo:

{descreva: tamanho do time, tempo juntos, principais desafios, últimos resultados}

Quero:
→ Pontos de atenção por categoria (engajamento, produtividade, relacionamento)
→ Sinais de alerta que podem ser invisíveis para mim
→ Recomendações práticas de curto prazo
→ O que monitorar nos próximos 30 dias
```

> O que você não vê de dentro, a IA ajuda a enxergar de fora.
