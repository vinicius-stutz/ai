# 7 Prompts Inteligentes para Compras Online
Use estes prompts para tomar decisões de compra mais inteligentes, comparar produtos e evitar armadilhas de consumo.
## 1. Comparador de Produtos
```
Compare os seguintes produtos levando em consideração custo-benefício, durabilidade, avaliações de usuários e casos de uso recomendados. Apresente um resumo em tabela.

Produto A: {{NOME_ESPECIFICACOES}}
Produto B: {{NOME_ESPECIFICACOES}}
```
## 2. Detector de Armadilhas em Descrições de Produtos
```
Analise a descrição do produto abaixo e identifique: termos vagos, informações ausentes, possíveis exageros de marketing e pontos que devo verificar antes de comprar.

Descrição: {{TEXTO_AQUI}}
```
## 3. Simulador de Custo Real de Compra
```
Calcule o custo real desta compra considerando: preço, frete, possíveis taxas de importação, garantia estendida opcional e custo de manutenção médio anual estimado.

Produto: {{NOME}}
Preço: {{VALOR}}
Origem: {{NACIONAL/IMPORTADO}}
```
## 4. Gerador de Perguntas para o Vendedor
```
Com base na categoria do produto abaixo, gere uma lista de 10 perguntas essenciais que devo fazer ao vendedor antes de finalizar a compra.

Categoria: {{CATEGORIA}}
Produto: {{DESCRICAO}}
```
## 5. Analisador de Avaliações
```
Analise as avaliações abaixo e extraia: principais pontos positivos recorrentes, principais reclamações recorrentes, padrões suspeitos (avaliações falsas) e um veredicto objetivo.

Avaliações: {{AVALICACOES}}
```
## 6. Estrategista de Melhor Momento para Comprar
```
Com base no tipo de produto abaixo, me oriente sobre: melhor época do ano para comprar, sazonalidade de preço, eventos de desconto relevantes e estratégia para negociar.

Produto: {{CATEGORIA_NOME}}
```
## 7. Criador de Lista de Compras Otimizada
```
Organize a lista de itens abaixo por prioridade de compra, identificando o que comprar agora vs. o que pode esperar, e sugira alternativas mais econômicas quando possível.

Lista: {{ITENS_AQUI}}
Orçamento disponível: {{VALOR}}
```
