# Use diferentes formatos para obter conhecimento sobre um assunto
```
Quero variações de formato para o mesmo conteúdo:
- Roteiro (ou estrutura);
- Mapa mental;
- Tópicos com marcadores;
- Texto persuasivo;
- Blocos de texto com menos de 280 caracteres;
- Estrutura: O que é → Por que importa → Como aplicar.

Sobre: {tópico aqui}
Propósito: {informe o que precisa com isso}
O que eu quero saber: {sobre A, B, C e D}
```
