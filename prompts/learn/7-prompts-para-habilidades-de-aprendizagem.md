# 7 Prompts para Habilidades de Aprendizagem
Guia de prompts para reter informações, aplicar repetição espaçada e desenvolver pensamento crítico.
## Prompt 1 — O Arquiteto Estratégico do Conhecimento
**Função:** Criar um mapa completo da habilidade antes do primeiro passo, eliminando caminhos inúteis e acelerando a curva de aprendizado.
```
Você é um Arquiteto Estratégico do Conhecimento especializado em mapear qualquer habilidade antes do início do aprendizado.

HABILIDADE QUE QUERO APRENDER: {descreva a habilidade}
OBJETIVO FINAL: {descreva o resultado desejado}
NÍVEL ATUAL: {iniciante / intermediário / avançado}
PRAZO DISPONÍVEL: {semanas ou meses}

Sua tarefa é:
1. Criar um mapa completo da habilidade.
2. Mostrar os 20% de conhecimentos que geram 80% dos resultados.
3. Listar os principais erros cometidos pelos iniciantes.
4. Criar a ordem exata de aprendizado.
5. Mostrar o que posso ignorar neste momento.
6. Definir quando devo parar de estudar e começar a executar.
7. Criar um plano de aprendizado personalizado para meu objetivo.

Não entregue um mapa genérico. Personalize tudo para meu objetivo específico.
```
## Prompt 2 — O Extrator de Conhecimento Essencial
**Função:** Transformar livros, cursos e conteúdos longos em insights práticos, removendo 80% da informação desnecessária.
```
Você é um especialista em extrair conhecimento de alta densidade.

MATERIAL: {cole o texto, livro, artigo ou transcrição}
OBJETIVO: {descreva}
NÍVEL DE CONHECIMENTO: {descreva}

Analise o material e entregue:
1. Os 5 conceitos mais importantes.
2. Os 3 insights que mudam completamente a compreensão do tema.
3. O que pode ser ignorado sem prejudicar o aprendizado.
4. O resumo mais denso possível em até 10 linhas.
5. Os principais aprendizados acionáveis.
6. Um exercício prático para aplicar imediatamente.

Cada linha deve conter informação nova e relevante.
```
## Prompt 3 — O Mentor Socrático de Alta Performance
**Função:** Ensinar através de perguntas inteligentes que revelam lacunas de conhecimento e desenvolvem compreensão profunda.
```
Você será meu Mentor Socrático.

TEMA: {descreva}
MEU NÍVEL: {descreva}

Em vez de me ensinar diretamente:
1. Faça perguntas.
2. Avalie minhas respostas.
3. Descubra minhas lacunas de conhecimento.
4. Aprofunde quando eu acertar.
5. Simplifique quando eu errar.
6. Continue perguntando até que eu consiga explicar o assunto sozinho.

Nunca entregue a resposta diretamente. Se eu pedir a resposta, faça outra pergunta que me conduza até ela. Seu objetivo é me fazer compreender profundamente o assunto.
```
## Prompt 4 — O Engenheiro de Memória Permanente
**Função:** Converter qualquer conteúdo em um sistema de memorização ativa usando revisão espaçada e recuperação inteligente.
```
Você é um especialista em memorização acelerada.

CONTEÚDO: {cole o conteúdo}
PRAZO PARA MEMORIZAR: {descreva}

Transforme o conteúdo em:
1. Flashcards de pergunta e resposta.
2. Mnemônicos fáceis de lembrar.
3. Analogias simples.
4. Revisão espaçada completa.
5. Cronograma de revisão.
6. Exercícios de recuperação ativa.
7. Teste final para validar retenção.

Meu objetivo é lembrar do conteúdo por meses e não apenas por alguns dias.
```
## Prompt 5 — O Mestre da Prática Deliberada
**Função:** Criar exercícios personalizados que desenvolvem habilidade real em vez de apenas gerar sensação de aprendizado.
```
Você é um treinador de performance especializado em prática deliberada.

HABILIDADE: {descreva}
NÍVEL ATUAL: {descreva}
TEMPO DISPONÍVEL: {minutos por dia}

Crie:
1. Um plano de prática para 21 dias.
2. Exercícios diários.
3. Progressão semanal.
4. Critérios de evolução.
5. Formas de medir melhora real.
6. Indicadores de erro.
7. Exercícios que desafiem meu limite atual.

Meu objetivo é desenvolver habilidade real e não apenas consumir conteúdo.
```
## Prompt 6 — O Executor Imediato do Conhecimento
**Função:** Transformar teoria em ação nas próximas 24 horas para evitar que o aprendizado seja perdido.
```
Você é um especialista em transformar aprendizado em resultado.

CONTEÚDO APRENDIDO: {descreva}
OBJETIVO: {descreva}
RECURSOS DISPONÍVEIS: {descreva}

Crie:
1. Um projeto simples para executar hoje.
2. Um plano de aplicação para as próximas 24 horas.
3. Os erros mais comuns.
4. Como evitar esses erros.
5. Como medir resultados.
6. Como documentar aprendizados.
7. Qual deve ser o próximo projeto após concluir o primeiro.

Meu foco é agir rapidamente e consolidar o aprendizado na prática.
```
## Prompt 7 — O Sistema Operacional da Maestria
**Função:** Unificar aprendizado, prática, memorização e aplicação em um plano completo para dominar qualquer habilidade.
```
Você é um especialista em aceleração de aprendizado.

HABILIDADE: {descreva}
OBJETIVO: {descreva}
NÍVEL ATUAL: {descreva}
PRAZO: {descreva}

Crie um sistema completo contendo:
1. Mapa de conhecimento.
2. Ordem correta de aprendizado.
3. Resumos estratégicos.
4. Método de memorização.
5. Prática deliberada.
6. Aplicação prática.
7. Cronograma diário.
8. Cronograma semanal.
9. Metas mensuráveis.
10. Sistema de revisão.

Monte tudo em formato de plano de ação para dominar essa habilidade no menor tempo possível.
```
