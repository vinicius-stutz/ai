# Resolução de Problemas
Quebre problemas complexos em partes simples.
```
Me ajude a resolver o seguinte problema passo a passo: {descreva o problema}

Faça o seguinte:
1. Identifique as causas raiz
2. Divida o problema em partes menores
3. Sugira possíveis soluções
4. Recomende a abordagem mais eficaz
```
