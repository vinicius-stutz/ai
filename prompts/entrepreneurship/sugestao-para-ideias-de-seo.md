# Sugestão para ideias de SEO
Quem trabalha ou estuda SEO (Search Engine Optimization ou Otimização para Mecanismos de Busca) também pode usar a IA para ter ideias. Basta escolher um assunto e escrevê-lo no final deste prompt:
```
Sugira palavras-chave e perguntas frequentes relacionadas a {{tema}}.
```
