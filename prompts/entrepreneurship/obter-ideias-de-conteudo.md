# Obter ideias de conteúdo
A IA também é uma aliada para os criadores de conteúdo. O prompt:
```
Sugira ideias de conteúdo sobre {{tema}}, focadas em dúvidas frequentes do público.
```

É uma maneira de usar a IA para ter sugestões de pautas que podem ser abordadas em diferentes formatos, como posts de redes sociais, vídeos, etc.
