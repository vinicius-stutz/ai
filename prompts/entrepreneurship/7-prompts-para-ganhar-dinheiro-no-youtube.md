# 7 Prompts para Ganhar Dinheiro no YouTube
Prompts estratégicos para estruturar canais, roteiros e estratégias de monetização no YouTube.
## 1. Posicionamento e Nicho do Canal
```
Quero criar um canal no YouTube. Com base no meu perfil abaixo, sugira 5 possíveis nichos com alto potencial de monetização. Para cada nicho, indique: nível de concorrência, tipo de monetização mais indicado e estimativa de tempo até os primeiros resultados.

Meu perfil: {descreva seus interesses, habilidades e disponibilidade de tempo}
```
## 2. Roteiro de Vídeo Viral
```
Crie um roteiro completo para um vídeo do YouTube sobre o tema abaixo. O vídeo deve ter entre 8 e 12 minutos, com gancho nos primeiros 30 segundos, estrutura de história e CTA ao final.

Tema: {cole aqui}
Público-alvo: {descreva}
Tom: {educativo / entretenimento / motivacional}
```
## 3. Otimização de SEO para Título e Descrição
```
Crie 5 opções de título e uma descrição otimizada para SEO do YouTube para o vídeo abaixo. Use palavras-chave relevantes, gatilhos de curiosidade e mantenha o título abaixo de 60 caracteres.

Assunto do vídeo: {cole aqui}
Palavras-chave principais: {liste aqui}
```
## 4. Estratégia de Monetização Múltipla
```
Com base no meu canal abaixo, elabore uma estratégia de monetização que vá além do AdSense. Inclua: possibilidades de afiliados, produtos próprios, memberships, patrocínios e serviços.

Nicho do canal: {cole aqui}
Número de inscritos: {quantidade}
Visualizações médias: {quantidade por mês}
```
## 5. Plano de Conteúdo para 30 Dias
```
Crie um calendário de conteúdo para 30 dias para um canal do YouTube no nicho abaixo. Inclua: título do vídeo, formato (tutorial / vlogs / lista / análise), objetivo de cada vídeo e palavras-chave alvo.

Nicho: {cole aqui}
Frequência desejada: {número de vídeos por semana}
```
## 6. Script de Thumbnail e CTA
```
Crie o texto de thumbnail (máximo 5 palavras) e o CTA falado (máximo 20 segundos) para um vídeo sobre o tema abaixo. Foco em maximizar cliques e inscrições.

Tema: {cole aqui}
```
## 7. Análise de Concorrente e Diferenciação
```
Analise o canal do YouTube abaixo com base nos dados fornecidos e identifique: lacunas de conteúdo, oportunidades de diferenciação e os 3 vídeos com maior potencial de replicar o sucesso.

Canal concorrente: {nome ou URL}
Dados disponíveis: {descreva: número de inscritos, vídeos mais vistos, frequência de postagem}
```
