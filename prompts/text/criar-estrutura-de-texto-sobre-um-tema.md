# Criar estrutura de texto sobre um tema
Mais uma capacidade das IAs é oferecer uma estrutura de texto sobre determinado tema, para que o usuário possa adaptar e fazer ajustes. Trata-se de usar a IA para fazer rascunhos e organizar ideias e, em seguida, utilizá-las como inspiração para desenvolver um novo conteúdo autoral, por exemplo. O prompt é:
```
Crie um esqueleto de artigo sobre {{TEMA_AQUI}}, com título, subtítulos e tópicos.
```
