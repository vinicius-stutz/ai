# 4 Prompts para escrita e comunicação
## 1. Reescrever texto
Esses comandos costumam funcionar bem para estudantes, profissionais e criadores de conteúdo. Primeiro, selecione o texto desejado e, em seguida, envie o seguinte prompt para o Gemini:

```
Reescreva este texto de forma mais clara e objetiva, mantendo o significado original.
```
## 2. Ajustar tom
Usamos o mesmo texto do tópico acima para ilustrar como o Gemini também consegue ajustar o tom de um conteúdo. Para isso, pegamos o prompt:

```
Adapte este texto para um tom mais {{formal/informal/profissional/didático}}.
```
## 3. Correção
Ainda levando em consideração o texto da reciclagem usado nos exemplos acima, desta vez pedimos para o Gemini analisar o conteúdo em busca de possíveis erros e melhorias. Neste exemplo, o prompt usado foi:

```
Revise este texto corrigindo erros gramaticais e sugerindo melhorias de clareza.
```
## 4. Explicação para público leigo
Mais uma habilidade do Gemini é explicar conteúdos para pessoas que não estão familiarizadas com o tema. A sugestão é usar este prompt:

```
Explique este assunto para alguém que não tem conhecimento técnico.
```
