# 7 prompts do ChatGPT que melhoram qualquer texto sem criar palavras por você
Fonte: https://canaltech.com.br/inteligencia-artificial/prompts-chatgpt-para-melhorar-qualquer-texto/.

Por [Viviane França](https://canaltech.com.br/equipe/viviane-franca/) e [Jones Oliveira](https://canaltech.com.br/equipe/jones-oliveira/) _(com adaptações)_.

## 1. Teste sua ideia
```
Estou pensando em escrever um artigo argumentando que {{IDEIA}}. Não me ajude a escrevê-lo. Diga-me o que há de fraco na premissa, o que estou assumindo como verdade sem provas e onde um leitor cético poderia contra-argumentar.
```

## 2. Peça que a IA te faça perguntas
```
Aqui está o que eu sei sobre {{TOPICO}}. Quais perguntas você gostaria de ver respondidas antes de sentir que entendeu completamente essa história? Não responda às perguntas. Apenas me diga o que eu devo investigar.
```

## 3. Não use a IA para substituir sua pesquisa
```
{{MATERIAL_RELEVANTE}} Explique isso para mim como se eu fosse inteligente, mas completamente novo neste assunto. Atenha-se apenas às informações que eu forneci. Diga-me se minha pergunta não puder ser respondida a partir delas.
```
## 4. Solicite que o ChatGPT discorde de você
```
Crie o argumento mais forte possível contra a minha posição. Quais evidências ou raciocínios alguém usaria para contestá-la?
```
## 5. Pergunte se seu rascunho fica entediante
```
Leia isto como um leitor impaciente. Diga-me os três lugares onde é mais provável que você pare de ler. Não reescreva nada. Explique por que você perdeu o interesse. Segue o texto: {{TEXTO_AQUI}}
```

## 6. Deixe a IA te ajudar a encontrar seus hábitos de escrita
```
Não reescreva isso. Analise meus hábitos de escrita. Procure por palavras repetidas, frases, estruturas de sentenças, qualificadores desnecessários, clichês e padrões em que estou confiando com muita frequência. Segue o texto: {{TEXTO_AQUI}}
```

## 7. Peça uma última revisão crítica
```
Atue como um editor final cético. Não reescreva nada. Identifique alegações factuais que eu devo verificar, suposições que estou fazendo, contradições ou inconsistências, lugares onde não sustentei meu argumento e perguntas que um leitor ainda possa ter ao terminar. Segue o texto: {{TEXTO_AQUI}}
```
