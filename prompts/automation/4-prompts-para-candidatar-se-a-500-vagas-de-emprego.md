# 4 Prompts para candidatar-se a 500 vagas de emprego
> [!NOTE] Atenção!
> Testado com o ChatGPT.

1. Envie seu currículo para o app via upload e escreva:
```
Assuma o papel de um recrutador senior. Com base no meu currículo, liste os 20 cargos para os quais sou mais qualificado e as palavras-chave exatas que os sistemas ATS procuram em cada um deles
```

2. Na mesma conversa, diga:
```
Reescreva meu currículo como um modelo principal que eu possa adaptar rapidamente. Use a fórmula XYZ do Google e remova todos os sinais de alerta que um recrutador percebe nos primeiros dez segundos
```

3. Ative o modo agente (certificar que o modo agente foi substituído pelo *ChatGPT Work*) e escreva:
```
Acesse o Linkedin e o Indeed, encontre todas as vagas relacionadas a esses cargos publicados nos últimos sete dias e crie uma planilha com o link, a porcentagem de compatibilidade e uma versão personalizada do meu currículo para cada vaga encontrada.
```

   4. Por fim, escreva:
```
Candidate-se às 500 vagas com mais compatibilidade e personalize cada candidatura com base na descrição da vaga
```
