# 11 Prompts para Organizar as Finanças Pessoais
Prompts para categorização de gastos, análise orçamentária e planejamento financeiro.
## 1. Organizar Gastos por Categorias
```
Vou te enviar meus gastos do mês em formato de lista. Organize tudo em categorias como alimentação, moradia, transporte, lazer e extras. Some cada categoria, calcule a porcentagem sobre o total e me entregue um resumo claro do meu padrão de consumo.

Gastos: {liste aqui}
```

## 2. Criar um Orçamento Mensal Personalizado
```
Meu salário mensal é {valor} e minhas contas fixas somam {valor}. Com base nisso, crie um orçamento mensal dividindo valores para alimentação, transporte, lazer, emergências e metas financeiras. Quais limites de gastos você recomenda para cada categoria?
```

## 3. Identificar Gastos Desnecessários
```
Aqui estão meus gastos das últimas semanas: {lista}. Analise tudo e destaque despesas que parecem desnecessárias, repetidas ou acima do usual. Explique por que elas chamam atenção e sugira formas de reduzi-las sem comprometer minha rotina.
```

## 4. Construir um Plano de Metas Financeiras
```
Quero atingir estas metas financeiras: {lista com valores e prazos}. Crie um plano dividido por meses mostrando quanto preciso guardar em cada etapa. Considere minha renda atual e indique estratégias para tornar essas metas mais viáveis.
```

## 5. Criar uma Tabela de Controle Mensal
```
Crie uma tabela mensal com colunas para data, descrição do gasto, categoria, valor e forma de pagamento. Depois, gere fórmulas simples que eu possa usar no Excel ou Google Planilhas para calcular totais e acompanhar meu orçamento ao longo do mês.
```

## 6. Orçamento Claro
```
Aqui estão minha renda e despesas mensais: {insira valores}. Monte um orçamento realista e sem estresse que inclua economias, custos fixos e um pouco de gastos sem culpa.
```

## 7. Detector de Vazamentos Financeiros
```
Com base nessas despesas: {liste}, em quais categorias estou gastando demais e como posso reduzi-las sem me sentir privado?
```

## 8. Aumentar a Renda
```
Com minha renda atual de {valor}/mês, sugira 3 formas de renda extra que eu possa aplicar de forma realista, com baixo custo inicial e bom ROI em 30 dias.
```

## 9. Poupança Inteligente
```
Desenhe um plano de poupança que me ajude a montar uma reserva de emergência de 3 meses, com base em {prazo desejado} de acordo com minha renda e despesas atuais.

Renda mensal: {valor}
Despesas fixas: {valor}
```

## 10. Redução de Dívidas
```
Aqui estão minhas dívidas: {liste dívidas, taxas de juros e pagamentos mensais}.

Crie um plano de pagamento agressivo, mas possível, usando o método avalanche ou bola de neve.
```

## 11. Orçamento Baseado em Zero
```
Me ajude a construir um orçamento baseado em zero para o próximo mês, onde cada real seja atribuído a um propósito — incluindo diversão, poupança e auto-investimento.

Renda do mês: {valor}
```
