# 9 Prompts para Edição e Geração de Imagens com Nano Banana
Guia de Prompts para Edição e Geração de Imagens com Nano Banana"
description: "Guia prático de prompts para ajustes de iluminação, textura e geração de imagens no Gemini com modelo Nano Banana.

## Para corrigir iluminação ruim
```
Ajuste avançado de iluminação em imagem com baixa qualidade de luz. Manter totalmente o rosto e a identidade da cena. Suavizar sombras fortes em regiões como olhos, nariz e queixo, simulando iluminação de flash equilibrada. Corrigir dominantes de core (amarelado, esverdeado ou azulado) para tons de pele naturais. Recuperar áreas escuras sem estourar luz. Resultado final: aparência de foto noturna com flash bem controlado, pele realista, sem sinais de edição.
```

## Para melhorar qualidade da foto
```
Recuperar imagem com baixa resolução ou leve desfoque, aumentando nitidez e definição sem alterar identidade. Refinar detalhes faciais (olhos, pele, cabelo) mantendo textura natural, sem efeito plástico. Reconstruir microdetalhes com base em padrões realistas. Reduzir ruído e artefatos de compressão. Preservar cores, iluminação e composição original.
```

## Para transformar selfie em retrato
```
Converter selfie no espelho em retrato profissional, como se fosse feito por outra pessoa. Preservar completamente rosto e corpo. Remover celular, moldura do espelho e reflexos. Ajustar postura do braço para algo mais natural. Criar fundo limpo com leve desfoque (bokeh). Corrigir perspectiva para aparência não reflexiva. Resultado: retrato equilibrado, natural e bem enquadrado.
```

## Para criar foto profissional
```
Gerar retrato corporativo profissional a partir da imagem base, mantendo identidade perfeita. Enquadramento em cabeça e ombros, seguindo composição equilibrada. Fundo neutro com leve desfoque (tons cinza ou azul). Simular lente 85mm com profundidade suave. Iluminação estilo estúdio (3 pontos), com luz principal difusa e leve recorte. Roupa formal e aparência alinhada ao ambiente profissional.
```

## Para corrigir linha do cabelo
```
Ajuste sutil e realista da linha capilar com base na imagem original. Preencher entradas mantendo textura, cor e densidade compatíveis. Reposicionar levemente a linha do cabelo (entre 5-10mm) de forma natural (curva suave ou formato levemente arredondado). Preservar totalmente rosto, expressão e estilo original. Resultado: cabelo mais preenchido, natural e sem aparência artificial.
```

## Para mudar a cor da roupa
```
Alterar apenas a cor da roupa de {cor atual} para {nova cor}. Manter 100% do restante intacto: pele, rosto, cabelo, cenário e acessórios. Respeitar textura do tecido (algodão, jeans, etc), sombras, brilho e caimento. Evitar vazamento de cor para outras áreas. Resultado: troca de cor realista e imperceptível.
```

## Para ajustar postura
```
Correção leve da postura corporal mantendo naturalidade. Reposicionar ombros levemente para trás, alinhar cabeça e ajustar coluna de forma sutil. Preservar expressão, identidade, roupas e iluminação original. Adaptar a roupa à nova postura com caimento realista.
```

## Para fazer foto de produto
```
Transformar imagem em fotografia profissional de produto para e-commerce. Manter fidelidade total da marca, cor e formato. Posicionar sobre superfície limpa (branca ou mármore claro). Fundo minimalistmo com leve degradê. Iluminação de estúdio: luz principal suave a 45°, preenchimento leve e contra-luz sutil. Resultado: imagem nítida, comercial e com estética premium.
```

## Para remover olheiras
```
Redução natural de olheiras e bolsas mantendo realismo. Suavizar pigmentação escura, reduzir leve inchaço e equilibrar sombras. Misturar tons com a pele ao redor sem perder textura. Preservar linhas naturais e estrutura facial. Resultado: aparência descansada, sem efeito artificial.
```

## Para fazer foto de passaporte
```
Gerar foto estilo documento oficial a partir da imagem fornecida. Enquadramento frontal (cabeça e ombros), expressão neutra e boca fechada. Manter identidade 100%. Iluminação uniforme, frontal e sem sombras. Fundo branco limpo e homogêneo. Resultado: foto nítida, padrão profissional e válida para documentos.
```
