# Prompt para fotos sem modificar a fisionomia
Importante para preservar a fisionomia na criação de artes e fotos derivadas dentro de IAs generativas. Ideal para ser usadno em conjunto com outros prompts ou para anexar à _skills_.

```
Crie uma arte usando esta foto como referência, preservando fielmente a identidade da pessoa. Mantenha inalterados os traços faciais, formato do rosto, proporções, expressão e características individuais. Não embeleze, e não modifique a fisionomia. Altere apenas os elementos solicitados na criação da arte.
```
